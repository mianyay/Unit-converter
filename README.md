# Unit-converter
Convert American to Australian (or pretty much other parts of the world's) units and vice versa!

## Live demo
https://mianyay.github.io/Unit-converter/

## About
You can convert units in the categories of length, weight, temperature, and time, based on the subcategories available. Track your conversions in the conversion history on the side!

## Features
- Convert units in a variety of categories
- Conversion tracker table
- Delete individual conversion tracker entries
- Delete the whole history in the tracker
- Save to local storage
- Pixel font
  
## How to run
Download the files and open index.html in a browser.
